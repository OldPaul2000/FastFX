StyleSetter{
    -setGlobalStyle(style): it should be located in the controller where the @FXML objects are located
                            and iterate through all of them and apply the style
    -setStyle(Node, style): takes the node and the style as arguments and pass that style to StyleParser.
                            It adds that style to StyleCache and the node to ElementsCache class
    -addStyle(Node, style): adds new property to existing style if not exists
    -removeStyle(Node): remove the style from that node and from the StyleCache
    -removeProperty(Node, property): removes property from existing style if exists
    -updateStyle(Node, newPropertyValue): updates the node's style by searching for that specific property
                 or properties and updates only that properties without parsing the entire initial style
                 and also updates the style in the style cache(the string value)
}

StyleOrderManager{
    - when input style is passed to the setStyle method, the properties should be sorted first
      in order to avoid style conflicts or properties which can't be applied because they are related
      to another one.
      e.g: if we set border radius in percentage before we set the width and height
           it won't be able to calculate the border radius if there is no width and height specified
      so if we set border radius and the height, the algorithm should put height before border radius.
}

StyleSplitter{
    ✔ -splitProperties(inputStyle): splits the property value pairs from the input string style
    ✔ -splitPropertyValue(propertyValue): splits the given property value pair
}

PropertyParser{
 -functional interface which will be used to create separate lambda function for each style property
  which takes as arguments the node and the property value as a string and then parses it accordingly.
  The functions will be stored and retrieved from ParserFunctions class
}

StyleCache{
    -setStyle(Node, style): adds the set style in a HashMap<styled node, the string style>)
    -addStyle(Node, style): adds a new property to the existing style
    -removeStyle(Node): removes the style by passing the styled node)
    -updateStyle(Node, style): updates the specified property for the specific node)
    -getStyle(gets the style by the specified node)
}

ElementsCache{
    -addElement(Node): adds the node in cache
    -removeElement(Node): removes the node from cache
    -addLookedUpNode(Node): when lookup function is executed it stores that element in
                            looked up nodes Map<parent node, lookedup node>.
                            When a style needs to be applied to a child node
                            first the lookedUpNodes hashmap will be checked if that
                            looked up node exists, if exists the lookup will not
                            be executed again
    //lookedup node is a child node from a parent node
    // When an id will be specified for the lookup the getChildren method will be used
    // and a full iteration will be performed and search that node with that specific id.
    // If a Node class name will be specified(e.g: AnchorPane, Button etc), lookup
    // method will be executed and retrieve all elements of that type.
    // These functions will be performed when styling a child node:
    // Style example: "bc-c:#142ef4, br-r:8px, RadioButton{bc-c:black, w:20px}" -> this will apply the
    // style from the curly braces to all RadioButton children of that element.
    // Style example: "bc-c:#142ef4, br-r:8px, radioButton1{bc-c:black, w:20px}" -> this will apply the
    // style from the curly braces to specified child(by id) of that element.

    p - Store the elements with their id(elements should be able to be retrieved

}

ElementsManager{
    -createElement(nodeName,id(optional), parent(optional),style(optional)):
            creates a new element by taking the nodeName as a string variable
            and takes the corresponding element class from ElementsConstants class,
            then creates a new element using java reflection or separate lambda functions,
            each for creating e different Node type(e.g: Button, AnchorPane etc.) same as
            PropertyParser. If the latter approaching will be used a ElementCreators class
            needs to be created to store those createElement lambda methods.
            The method will return that element.
            If parent is specified the element will be added to specified parent
            right after creation, same with style(will be added after element creation).
            It should also apply the global style.
    -deleteElement(node),
}

StyleValuesCache{
    - Stores the applied style values (e.g: applied width value) for every element
      to be able to take it into account when applying another relevant style.
      e.g: when margin is applied it needs to take that value into account
           when the design is responsive
}
